Nota (despliegue): este recorrido corresponde a la version con pestanas y

La seccion de errores y rechazos se reprodujo con el backend local porque una
instancia de Vercel usa una base efimera en /tmp y no permite detener el servidor
desde el navegador.

Nota (acceso): el recorrido se realizo despues de iniciar sesion desde la pantalla
de acceso con un rol demo. El token quedo solo en memoria y se envio en las
escrituras; la consulta GET del catalogo es publica en la API.

Estados y errores de comunicacion
------------------------------------------------------------------------------

mientras duraron las peticiones y se rehabilitaron al terminar; no se observaron
errores de JavaScript en la consola (solo los 400 y 409 esperados del contrato).

Backend detenido, accion Consultar catalogo (la pagina tenia 3 filas):
  "Consultar catalogo: el servidor no esta disponible (HTTP 502). El resultado
   no queda confirmado; no reintente automaticamente. La tabla se limpio para
   no mostrar datos anteriores como vigentes."

Backend detenido, accion Crear ficha:
  "Crear ficha: el servidor no esta disponible (HTTP 502). El resultado no queda
